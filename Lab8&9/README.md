# Deep Learning Lab – Experiments 8 & 9

## Effect of Attention Type and Attention Position in a Pretrained ResNet50

This experiment investigates how different attention mechanisms and their insertion positions affect image classification performance using an ImageNet-pretrained ResNet50 on the **TensorFlow Flowers dataset**.

### Experiments Covered
- Channel and spatial attention
- Sequential channel–spatial attention
- Self-attention
- Attention-type and attention-position ablation
- Multi-stage attention and attention ordering
- Spatial attention kernel-size comparison
- SE, ECA, and CBAM comparisons
- Performance evaluation using accuracy, precision, recall, macro F1-score, parameter count, and inference time
- Attention-map and Grad-CAM visualization

### Technologies
Python, TensorFlow/Keras, ResNet50, NumPy, Matplotlib, and scikit-learn.

### Objective
To analyze the effectiveness of different attention mechanisms and understand the trade-offs between classification performance, model complexity, and inference time.
